# step1
- num1とnum2の総当たりの合計とpairを記録していく
 - 合計をsortして、小さい順からk番目までのpairをreturnする
 - ループの計算量がO(m*n)でsortの計算量がO(logn)で大きそう。。
- heapに全部入れてk番目までpopする
 - 全部入れなくてもよさそう。  

step1,2,commitせずに削除してしまいました。。。のでできるだけ再現。

```python
class Solution:
    def kSmallestPairs(self, nums1, nums2, k):
        pairs = []
        for i in range(len(nums1)):
            for j in range(len(nums2)):
                sum = nums1[i] + nums2[j]
                pairs.append((sum, nums1[i], nums2[j]))
        pairs.sort()
        return [[u, v] for s, u, v in pairs[:k]]
```


# step2

forの中で合計を出さなくても、sortのキーのタイミングで合計でソートして、k番目までを取り出せばいい。ただし、計算量が大きいのでテストはパスしない。

```python
class Solution:
    def kSmallestPairs(self, nums1: List[int], nums2: List[int], k: int) -> List[List[int]]:
        pairs = []
        for u in nums1:
            for v in nums2:
                pairs.append([u,v])
        pairs.sort(key=sum)
        return pairs[:k]
```

```python
class Solution:
    def kSmallestPairs(self, nums1: List[int], nums2: List[int], k: int) -> List[List[int]]:

        heap= []
        visited = set()

        heapq.heappush(heap, (nums1[0]+nums2[0], 0, 0))
        visited.add((0,0))

        smallest_sum_k_pairs = []
        while heap and len(smallest_sum_k_pairs) < k:
            _, i, j = heapq.heappop(heap)
            smallest_sum_k_pairs.append([nums1[i],nums2[j]])

            if i + 1 < len(nums1) and (i + 1, j) not in visited:
                heapq.heappush(heap,(nums1[i + 1] + nums2[j], i + 1, j))
                visited.add((i + 1, j))
            
            if j + 1 < len(nums2) and (i, j + 1) not in visited:
                heapq.heappush(heap,(nums1[i] + nums2[j + 1], i , j+1))
                visited.add((i, j + 1))
          
        return smallest_sum_k_pairs  
```
